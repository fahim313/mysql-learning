# MySQL Learning

A structured repository documenting my MySQL learning journey through SQL queries, table operations, constraints, operators, and built-in functions.

The goal of this repository is to build a strong foundation in SQL through practical examples and hands-on practice.

## Topics Covered

### 01. Basic Queries

- Create a database
- Create a table
- Insert data
- Update data
- Delete data
- Drop a table

### 02. Table Queries

- SQL constraints
- SELECT statements
- WHERE clause
- Arithmetic operators
- Comparison operators
- Logical operators (`AND`, `OR`)
- `DISTINCT`, `ORDER BY`, `LIMIT`, and `OFFSET`

### 03. Functions

- Create a dummy database for practice
- Practice SQL queries
- MySQL built-in functions
- Aggregate functions (`COUNT()`, `SUM()`, `AVG()`, `MIN()`, `MAX()`)

## How to Use

1. Clone the repository:

   ```bash
   git clone https://github.com/fahim313/mysql-learning.git
   ```

2. Open the project in your preferred code editor.

3. Run the `.sql` files using MySQL Workbench or the MySQL command-line client.

4. Follow the numbered files in each directory to learn the topics in order.

- Organize SQL scripts by topic.
- Track learning progress through Git commits.
